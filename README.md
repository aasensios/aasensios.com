# Personal website

Source of [asensio.me](https://asensio.me), built with [Astro](https://astro.build/) and the [Vite+](https://viteplus.dev/) toolchain.

**Zero npm dependencies shipped.** Every package in `package.json` is a dev dependency used only to build, check and test. The site is static HTML and CSS with a few lines of inline script, self-hosted fonts and inline SVGs: no frameworks, no CSS libraries, no third-party requests.
